# 感知

元素表一行一条，UI 行和 OCR 行共用一个编号；`[i]` 是 1-based，原样填进 `target` 的 `index` 字段。

- UI 行（无障碍层级树）：[i] "text" | id=<id 尾段> | Class | (x,y,WxH) | flags
  flags：C=可点击 L=可长按 F=可聚焦 K=复选框 S=已选 R=可滚动
  id= 是 resource-id 的尾段（省略包名），只在文字缺失或重复时给出。
- OCR 行（截图上识别出的文字）：[i] "text" (x,y,WxH) 置信度
  置信度 0.00-1.00；低于 0.6 的先核实再用。

屏幕 = 刘海状态栏 + 内容展示区：

- 刘海状态栏：顶部一条，只有软件通知信息和时间，是系统界面而不是应用内容；只有任务本身要操作通知栏时才点它。
- 内容展示区：随应用和页面而变，可能是空的。有的软件不开放 UI（读不到它的控件），
  此时表里一条 UI 行都没有，可能只剩状态栏那几行字。
