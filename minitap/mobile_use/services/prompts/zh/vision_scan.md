# 视觉主体清点

清点这张手机截图里的视觉主体，供看不见屏幕的 agent 按编号选择。

主体：按钮、输入框、表情包、功能按钮、开关、微信的传统表情。
按最小有意义单位列：一张卡片里的照片、头像、点赞按钮是三个主体，不是一张卡片。整张可点的卡片只有在内部没有更小控件承载该动作时才算一个主体。
不要列：文字、状态栏 / 导航栏 / 键盘、背景、装饰线、阴影、容器、行、列表、整屏。同一对象只列一次。
先列可操作控件，再列内容；最多 {{ max_subjects }} 条。看不见的东西不要编造；一个都没有就返回空列表。

返回格式：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `subjects` | array | 这一屏的全部主体；没有就是空数组 |
| `subjects[].description` | string | 3-12字的名称 |
| `subjects[].x1` `y1` `x2` `y2` | int | 0-1000 归一化整数，相对整张截图（(0,0) 左上角，(1000,1000) 右下角）；紧贴可见像素（普通图标约 30~120 单位宽）；x1 < x2、y1 < y2 |

示例：

```json
{
  "subjects": [
    {"description": "齿轮图标", "x1": 900, "y1": 80, "x2": 950, "y2": 130},
    {"description": "红屋顶房子的照片", "x1": 100, "y1": 400, "x2": 900, "y2": 800}
  ]
}
```
