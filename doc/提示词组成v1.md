### 变的条件

| 字段 | 触发时机 | 代码位置 |
|---|---|---|
| Subgoal Plan | 子目标状态流转 `(not started yet)` → `⏳` → `✅`/`❌`；完成原因追加；replan 时整表被换掉（新 ID） | `planner.py:160`、`orchestrator.py:104-121` |
| Current Subgoal | orchestrator 推进后指向下一个 `PENDING` 子目标 | `orchestrator.py:121` → `start_next_subgoal` |
| Executor Feedback | 上一轮 executor 的 ToolMessage 汇总；首轮无决策时为 `None.` | `cortex.py:270-293` |

### 不变的条件

| 字段 | 为什么不变 |
|---|---|
| Initial Goal | `state.initial_goal` 全程只读不写 |
| Locked App | 来自 `ctx.execution_setup.app_lock_status`，任务启动时锁一次；没开 app lock 时整行因 `{% if %}` 消失 |

## 二、system prompt 之外的每轮消息

Cortex 每轮发出的 `messages` 里**没有任何 AIMessage**，不是多轮对话，而是全量重发。以下 5 条 HumanMessage 全部每轮变：

| 顺序 | 内容 | 变/不变 | 条件 | 代码位置 |
|---:|---|---|---|---|
| 1 | 设备信息 + 日期 + 当前前台 app | 变 | 总是 | `cortex.py:166-174` |
| 2 | 最近 25 条 agent thoughts | 变 | 有 thoughts 时 | `cortex.py:180-186` |
| 3 | UI 层级树 | 变 | `ui_hierarchy` 开 + 本屏有树 | `cortex.py:188-193` |
| 4 | OCR 文本块 | 变 | `ocr` 开 + 有结果 | `cortex.py:194-199` |
| 5 | 截图 base64 | 变 | `screenshot` 开 + 有截图 | `cortex.py:200-206` |

所以这个系统的「跨轮记忆」只有两处：第 2 条 thoughts（上限 `MAX_CORTEX_AGENTS_THOUGHTS = 25`，`cortex.py:40`）和 system prompt 第 22 行的 Executor Feedback。
